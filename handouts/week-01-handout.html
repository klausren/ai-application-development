5 · The three lines you will write all semester 贯穿全学期的三行

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

model = LogisticRegression(max_iter=200)
model.fit(X_tr, y_tr)              # 1 · LEARN   from training data
preds = model.predict(X_te)        # 2 · APPLY   to unseen data
print(model.score(X_te, y_te))     # 3 · MEASURE on the test set
fit → predict → evaluate. Every model you meet this semester — logistic regression, random forest, a neural network, BERT — obeys exactly these three steps. Only the middle object changes. 本学期所有模型都服从这三步，变的只是中间那个对象。
