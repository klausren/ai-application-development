# 修订记录 · W07 / W08 表格数字的千分位分隔符

> **2026-10-26** ｜ 任老师指出：week 07 课件表格里的数字显示有问题，例如 `8 256`。

---

## 一、问题

W07（及 W08）部分表格与正文里，**四位以上数字的千分位用空格分隔**：

```
参数        累计
8 320       8 320
8 256       16 576
1 168       1 248
```

中文读者极易把 `8 256` 读成"8 和 256"两个数。

## 二、根因（不是笔误，是惯例缺口）

| 证据 | 结论 |
|---|---|
| `scripts/deck_specs/week_04.py` L600/L603 用的是 `"4,482"`、`"67,074"` | **逗号才是本课程既定惯例**（同为"参数量"表、同为周课件） |
| W07 规格里英文 note 本来就写 `"17,226 → 1,898"` | 规格作者知道该用逗号，**只是表格数据行与中文文案手写时漏了** |
| `week_07.py` 顶部注释明写 *"Do NOT hand-edit those numbers; re-run the script instead"* | 这些参数量**是手写字面量**，违反了规格自己的纪律 |
| `outputs/w7_cnn.json` 里是 `1898` / `17226` / `21312`（无分隔符） | **数值本身完全正确**，错的只有显示分隔符 |

⇒ 空格千分位是 **W07/W08 的孤例**，不是全课程惯例。
