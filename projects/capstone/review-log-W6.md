## 1. 逐人审定（90 秒/人）

**90 秒内必须听到三件事**，缺任一项即判「未就绪」：

1. **用户是谁**——一个具体的人做一件具体的事。「所有人 / 学生 / 老师」**不是用户**。
2. **数据从哪来 + 许可是什么**——说不出源与许可，选题不成立。
3. **要打败的笨基线是什么**——多数类 / 经验规则 / 上周的模型。**打败它不算本事 = 没有项目。**

| # | 姓名 | 用户（1 句） | 数据来源 + 许可 | 笨基线 | 裁决 | 一句话范围 | Cut list（明确不做） | 选手 |
|:---:|---|---|---|---|:---:|---|---|:---:|
| 1 | | | | | 定 / 改 / 驳 | | | A/B/C/D |
| 2 | | | | | 定 / 改 / 驳 | | | A/B/C/D |
| 3 | | | | | 定 / 改 / 驳 | | | A/B/C/D |
| 4 | | | | | 定 / 改 / 驳 | | | A/B/C/D |
| 5 | | | | | 定 / 改 / 驳 | | | A/B/C/D |
| 6 | | | | | 定 / 改 / 驳 | | | A/B/C/D |

**裁决含义**

- **定** — 当场收，写进共享看板，状态置 `已定题`。
- **改** — 方向保留，但用户／数据／基线之一不成立；**当场给出要改的那一项**，W7 课前重提。
- **驳** — 不可行（数据拿不到 / 无许可 / 基线无法定义）；**从选题库另选**，W7 课前重提。

**选手图例**（来自 `topic-catalogue.md` 的 21 个种子，按难度递增）

| 代号 | 含义 |
|:---:|---|
| **A** | 入门级，数据完全离线、任务定义明确 |
| **B** | 需要一点数据工程，仍属单模型可解 |
| **C** | 需要一次方案对照（两个模型 / 两种表示） |
| **D** | 需要外部数据或接口，风险较高，需教师确认许可 |
| **D1** | **保底选题**：用仓库自带 `data/raw/defects.csv`（12 480 行，零下载、零许可风险，含真实数据泄漏陷阱） |

> **保底规则**：W6 课内未定题、或 W7 课前仍未重提成功者，**由教师直接指定 D1**。
> 先动起来比选题漂亮重要——这句话要当着全班说，说给卡住的那个人听。
