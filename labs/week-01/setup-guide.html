1Install Miniconda

Download the Python 3.11 installer for your OS from anaconda.com/download (choose Miniconda, the small one ~80 MB).

  • Windows: run the .exe. Accept defaults, but check "Add to PATH" when offered. After install, use Anaconda Prompt (search it in the Start menu) — not the plain cmd.
  • macOS: run the .pkg, accept defaults. Then open Terminal and run conda init zsh, and reopen Terminal.
  • Linux: bash Miniconda3-latest-Linux-x86_64.sh

Verify — open a new terminal and run:

conda --version
# expect something like: conda 24.x.x

2Create the course environment

Copy-paste these commands one block at a time:

# 1. create an isolated environment named "ai-app"
conda create -n ai-app python=3.11 -y

# 2. activate it (do this EVERY lab session)
conda activate ai-app

# 3. install the semester's toolkit (~5-10 min; torch is the big one)
pip install numpy pandas matplotlib seaborn scikit-learn torch jupyter

# 4. prove it works — trains a tiny model in ~1 second
python env_check.py

You should see a wall of [ OK ] lines and finish with:

ALL CHECKS PASSED - see you in the lab!
✅ That's the environment done. If any line prints [FAIL], jump to the FAQ below before asking in the group.

3Set up VS Code

  1. Install VS Code: code.visualstudio.com
  2. Open it → Extensions (Ctrl/Cmd+Shift+X) → install Python and Jupyter (both by Microsoft).
  3. Open your lab folder: File → Open Folder → week1-lab.
  4. Open Week1-Lab-Starter.ipynb. If asked "Do you trust this folder?" → Yes.
  5. Key step: click the kernel selector in the top-right → Select Kernel → Python Environments → ai-app (Python 3.11).
⚠️ The #1 Week-1 mistake: running with the wrong kernel (e.g. a system Python that lacks torch). If a cell says ModuleNotFoundError, check the top-right corner first.

4Git & GitHub

  1. Create a GitHub account (use a professional username — it goes on your CV): github.com/signup
  2. Install Git: git-scm.com/downloads (macOS: also works via xcode-select --install)
  3. Verify: git --version

The push commands themselves live in the Lab notebook (Part 4). Free reading if Git is new to you: Pro Git, chapters 1–3 (free e-book).

5Fallback — Google Colab (zero install)

No laptop? Install broke? Colab gives you a browser notebook with GPU, nothing to install:

  1. Go to colab.research.google.com (needs a Google account)
  2. File → Upload notebook → choose Week1-Lab-Starter.ipynb
  3. Runtime → Change runtime type → T4 GPU → Save
  4. Everything except the Git part works out of the box (torch/sklearn pre-installed)
⚠️ Colab free tier has daily usage limits and sessions disconnect after ~90 min idle — save to GitHub before closing the tab. Colab is a backup, not the main workflow: exams and some later labs require your local setup.

6FAQ — common errors & fixes

SymptomFix
conda: command not found Windows: use Anaconda Prompt, not cmd. macOS: run conda init zsh and reopen Terminal. Or reinstall with "Add to PATH" checked.
pip install is extremely slow / times out Use a mirror: pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <package>. In China this is dramatically faster.
pip install torch fails or is huge CPU-only version (enough for this course, ~200 MB instead of 2+ GB):
pip install torch --index-url https://download.pytorch.org/whl/cpu
ModuleNotFoundError: No module named 'torch' You forgot to activate the env (conda activate ai-app), or the notebook kernel is wrong — check top-right in VS Code. Not fixed? Re-run the pip install inside the activated env.
CondaHTTPError / SSL errors during conda create Usually campus proxy. Try phone hotspot, or configure the Tsinghua conda mirror (search "conda 清华镜像").
git push asks for a password and rejects it GitHub no longer accepts account passwords. Use a Personal Access Token as the password: GitHub → Settings → Developer settings → Tokens → Generate (scope: repo). Or install GitHub Desktop.
Colab: cannot connect / GPU unavailable Region restriction — use the local setup route (Sections 1–3), or try again at off-peak hours.
Notebook runs cells out of order and errors Always run top-to-bottom. Fix: Kernel → Restart & Run All — this is also how submissions are graded, so test it before you submit.
📌 Still stuck after trying the FAQ? Post in the class group with: (1) your OS, (2) the exact command you ran, (3) the full error message — screenshot of the whole terminal, not just the last line. Questions like "it doesn't work" get slow answers; complete bug reports get fast ones. This is also good practice: bug reports are a professional skill.
