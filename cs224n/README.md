# Stanford CS224n — Courseware Slot (Not Bundled)

> **Why is this folder (almost) empty?**
> Stanford CS224n publishes all lecture slides publicly, but does **not**
> attach an explicit open-source license to them. To respect that, this
> repository does **not** redistribute the PDFs. Instead, run the one-line
> downloader to fetch the official files straight from Stanford:

```bash
bash scripts/download_cs224n.sh
```

19 lecture PDFs (~90 MB) will land in this folder, verified and resumable.

## Usage Terms 使用边界

- ✅ Classroom display, self-study, linking, and citing the official source
- ✅ Downloading for personal / in-class use (that is what the script does)
- ❌ Re-uploading the PDFs to another public repo or repackaging them
- ❌ Commercial training use without Stanford's permission
