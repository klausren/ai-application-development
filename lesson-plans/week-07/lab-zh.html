1. 教学目标

知识目标

  • 说出实验协议中被固定的各项设置，并解释每一项为什么必须固定
  • 逐层对账 CNN（1,898）与全连接对照网（17,226）的参数量
  • 解释为什么 CNN 与 9.07 倍大的全连接网只差 0.0023 的测试准确率，以及为什么这要写成未观察到显著差异
  • 解释为什么 4.1 个点的测试准确率只取决于池化函数的选择
  • 解释为什么数据增强用 3.0 个点的干净精度换到了 29 个点的平移鲁棒性
  • 解释为什么混淆矩阵里 26 个错误中有 12 个与数字 8 有关

能力目标

  • 能用 nn.Conv2d、nn.MaxPool2d 与 nn.Linear 搭出 CNN，并在训练前用断言把每一层的形状与公式对齐
  • 能用一小段脚本数出参数量，而不是估算
  • 能训练 CNN、画出训练与验证曲线，并把五架构对照表读成「均值 ± 标准差」
  • 能打印混淆矩阵、点名最差类对及其次数，并给出至少 3 个错分样本及其概率
  • 能实测峰值内存随 batch 的变化，并用梯度累积复现等效 batch
  • 能向 AI 询问显存优化方案，逐条实测，并标注有效或无效
素质目标 · 思政 如实报告不成功的实验，也如实报告没帮上忙的优化。本实验里数据增强是故意压低干净分数的（0.9808 掉到 0.9504），而 AI 给的显存建议里会有一条经不起实测。两者都要留在报告里并被解释。这也是绿色计算的落地习惯：1,898 参数的 CNN 已经追平 17,226 参数的全连接网，所以先算清参数预算再加参数，先量出内存峰值再谈加硬件。

5. 代码骨架

把三种层补进去；形状链路是 8×8 → conv+P → 8×8 → pool → 4×4 → conv+P → 4×4 → pool → 2×2 → flatten 64 → FC 10。断言必须在任何训练开始前通过。

import torch, torch.nn as nn, torch.nn.functional as F

class CNN(nn.Module):
    def __init__(self, channels=(8, 16), n_classes=10):
        super().__init__()
        c1, c2 = channels
        self.conv1 = nn.Conv2d(1,  c1, kernel_size=3, stride=1, padding=1)  # 1x8x8 -> c1x8x8
        self.conv2 = nn.Conv2d(c1, c2, kernel_size=3, stride=1, padding=1)  # c1x4x4 -> c2x4x4
        self.pool  = nn.MaxPool2d(2)                                        # stride 2, halves the map
        self.fc    = nn.Linear(c2 * 2 * 2, n_classes)                       # flatten 16*2*2 = 64

    def forward(self, x):                      # x: (B, 1, 8, 8)
        x = self.pool(F.relu(self.conv1(x)))   # (B, 8, 4, 4)
        x = self.pool(F.relu(self.conv2(x)))   # (B, 16, 2, 2)
        x = x.flatten(1)                       # (B, 64)
        return self.fc(x)                      # (B, 10)

# 1) shapes: assert the formula against the real forward
def out_size(size, k, s, p):
    return (size + 2 * p - k) // s + 1
assert out_size(8, 3, 1, 1) == 8   # conv + padding keeps the size
assert out_size(8, 2, 2, 0) == 4   # pooling halves it

# 2) parameters: count them, do not estimate
n_conv = sum(p.numel() for p in CNN().parameters())
# conv1 = 3*3*1*8 + 8 = 80 ; conv2 = 3*3*8*16 + 16 = 1168 ; fc = 64*10 + 10 = 650
assert n_conv == 80 + 1168 + 650 == 1898

全连接对照网沿用第 4 周的 MLP：nn.Linear(64, 128) → nn.Linear(128, 64) → nn.Linear(64, 10)，共 17,226 个参数。增强臂只对训练批做随机 ±1 像素平移，测试批不平移。平均池化变体就是把 nn.MaxPool2d(2) 换成 nn.AvgPool2d(2)，其余逐字节相同。

6. AI 协同操作规程

先问、再实测、后标注

  1. 问：提示 AI 给出「降低本周模型显存占用」的办法。预期会得到「把 batch 减半」「用梯度累积」「用 torch.amp.autocast + GradScaler 做混合精度」「缩小输入」这类清单。
  2. 实测：在本机逐条运行并测量。batch 减半只改变内存；梯度累积用「按组内占比」权重时与真 batch 128 逐位一致（5/5），代价是时间、不是精度；混合精度会改变数值，必须重新确认指标没漂。
  3. 标注：每条建议标注有效或无效，并在旁边写上实测证据与代价。一条建议可以「在一般情况下成立」却在「这个任务上无效」——本周实测：这个模型永远不会 OOM（batch 1024 峰值仅 582.0 MB），所以「把输入缩到 16×16」只有代价、没有收益。
  4. 留痕：把记录留在报告里——提问、建议、实测、结论。用自己的实测删掉 AI 的建议，正是本环节要考核的能力。
必须核查的典型 AI 说法 「梯度累积总能省显存」只有在累积梯度被正确加权时才成立；用 none 与 unscaled 两种写法时，结果都不再与真 batch 一致（2/5 种子）。「一定要用混合精度」是用数值换内存，必须拿指标去核实。两条结论都来自学生自己的实测，不是来自 AI 的原文。

怎么读这张实测表 · 三条诚实的结论 1. CNN 追平了 9.07 倍大的全连接网：0.9808 对 0.9785 只差 0.0023，小于 0.0084 的标准差，唯一站得住的句子是未观察到显著差异。 2. 池化函数是设计选择：最大 0.9808 对平均 0.9400，参数量完全相同，差 4.1 个点。 3. 增强是一笔买卖、不是白赚：它买到 29 个点的平移鲁棒性（dx = −1 时 0.6481 → 0.9415），付掉 3.0 个点的干净精度（dx = 0 时 0.9808 → 0.9504）。
