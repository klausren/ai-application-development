1. Learning Objectives

Knowledge

  • State the Tom Mitchell definition of machine learning and name the three learning paradigms
  • Distinguish parameters from hyperparameters, and give three examples of each
  • Explain the roles of the loss function, gradient descent, and the learning rate
  • Explain the train / validation / test split and how k-fold cross-validation works
  • Read a (train score, validation score) pair and diagnose underfitting vs overfitting

Skills

  • Classify a new problem into supervised / unsupervised / reinforcement learning
  • Choose an appropriate loss or metric for a given task (classification vs regression)
  • Build a leakage-free Pipeline and tune it with GridSearchCV
  • Interpret best_params_, CV score and test score — and explain why they differ
Attitudes Internalise that "a model is only as trustworthy as the protocol that evaluates it". Train the habit of asking how was this number produced? before celebrating any score, and of writing down every modelling decision.

4. Key Activity Design

Activity 1 · Write Me a Spam Filter (L1, p4)

Ask the class to write if-then rules that catch spam email. Collect three attempts, then add one twist each ("what if the sender is a client named Cash?"). Within two minutes everyone agrees the rule list never ends — that is the exact moment machine learning becomes obvious: we supply examples, the algorithm supplies rules.

Activity 2 · Sort the Bucket (L2, p12)

Write eight items on the board — w, b, learning rate, C, a tree's split threshold, max_depth, coef_, cv — and have students sort each into learned vs chosen. Debrief with the one-liner: parameters are learned, hyperparameters are chosen, and GridSearchCV does the choosing.

Activity 3 · Blindfolded Descent (L3, p15)

A volunteer closes their eyes; the class guides them to the lowest spot in the room using only "warmer / colder" and step size. Then map it back: position = parameters, "colder" = gradient, step size = learning rate. Ask what happens if steps are tiny (forever) or huge (never settle) — the learning-rate trio lands without a formula.

Activity 4 · Read the Scoreboard (L4, p21)

Give four (train, validation) pairs — (62%, 60%), (98%, 72%), (95%, 93%), (58%, 91%) — and have students diagnose each in 30 seconds. The fourth row is the trap: it looks great and is broken (leakage or a bad split). This is the single most valuable 3 minutes of the session.

Activity 5 · Did Information Cross the Line? (L4–L5, p19 + p25)

Draw the split line on the board, then name operations one at a time — fit a scaler on all rows, median-fill before splitting, compute the mean over the whole column — and ask each time: "legal or leak?" Ends with the punchline that a Pipeline makes the legal version the default, which is exactly what the lab does next.
