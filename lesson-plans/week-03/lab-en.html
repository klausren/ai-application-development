Knowledge

  • Explain why a Pipeline exists and what it prevents (leakage in cross-validation)
  • State the difference between a parameter and a hyperparameter, and name what best_params_ holds
  • Explain why the CV score is usually a little lower than the test score
  • State which metrics belong to classification and which to regression

Skills

  • Build a Pipeline with preprocessing + model and use it like a single estimator
  • Run a hyperparameter sweep with GridSearchCV and read the results table
  • Switch the same workflow from classification to regression without changing the mental model
  • Push the M3 capstone milestone (repository + src/train.py) before the lab ends
Attitudes Treat reproducibility as part of the deliverable: if python src/train.py does not run on a fresh clone without edits, the work is not finished. Document decisions, do not hand-edit CSVs.

4. Key Activity Design

Activity 1 · Read the Warning Aloud (Lab A, p25)

Nobody may fix the ConvergenceWarning for the first two minutes — they must first write down what it says. This builds the reflex of reading diagnostics before reaching for a fix, and sets up Lab B where scaling resolves it.

Activity 2 · Two Models, One Leak (Lab B, p25)

Instructor shows two versions side by side: scaler fitted on all data (leaks) vs scaler inside the Pipeline (safe). Students predict which score is "too optimistic" before running either. The reveal: the leaking version reports a better number that nobody can trust.

Activity 3 · Guess C Before Running (Lab C, p26)

Students write down which C they expect to win and why, before running the sweep. Comparing predictions with best_params_ turns a mechanical exercise into a calibration exercise — and the "C too large overfits" story becomes personal.

Activity 4 · Explain R² to a Stranger (Lab D, p27)

Each student writes one sentence explaining R² = 0.45 to a non-technical stakeholder, then reads it to a neighbour. Most first attempts say "45% accurate"; the correction — "we explain 45% of the variation, versus simply guessing the average" — is the point.

Activity 5 · Fresh-clone reproducibility test (Lab E, p29)

Clone the repo on a different machine and run it there and run python src/train.py on their repository. Absolute paths, missing requirements and hardcoded filenames surface instantly — far more convincingly than any checklist.
