四、关键教学活动设计 Activity Design

活动 1 · 环境故障诊所（Lab A/B 之间）

预设 3 个典型报错投到屏幕：①版本冲突（numpy 2.x 与旧代码不兼容）；②conda 未激活就运行 python；③pip 网络超时。先让学生 2 人一组自行诊断 3 分钟，教师再给标准排查路径，并鼓励全班互相帮忙。Troubleshooting clinic — 3 pre-set errors, peer diagnosis first.

活动 2 · 模型对比挑战（Lab D）

完成 Iris 基线后，额外挑战：分别用 LogisticRegression 与 SVC 训练，记录准确率；再换 3 个 random_state 观察波动。完成最快的 3 名同学上台展示自己的结果表——引导讨论"模型选择与随机性"。

Challenge: compare two classifiers and 3 seeds; fastest 3 present their results.

五、实验步骤与要求 Lab Steps & Deliverables

  1. 环境搭建：创建 ai-app conda 环境（Python 3.11），安装 numpy pandas matplotlib seaborn scikit-learn torch jupyter，导出 environment.yml。
  2. Notebook 验证：新建 notebook，验证 import numpy, pandas, sklearn, torch 成功；在 Google Colab 打开同一文件并运行 torch.cuda.is_available()。
  3. Git 提交：本地 git init → add → commit → GitHub 新建仓库 → push。提交信息规范：feat: week1 lab environment setup；配置 .gitignore 排除 __pycache__ 与 .ipynb_checkpoints。
  4. 第一个模型：运行 Iris 分类程序；分别用 LogisticRegression 与 SVC 对比准确率；记录 3 种 random_state 的结果差异并写进 notebook 结论。
  5. 思考题（提交到 notebook 末尾）：举出 3 个身边产品并归类 ML/DL/GenAI；解释 random_state 对可复现性的意义；说明"训练模型"在 AI 项目生命周期中处于哪个阶段、占比如何。
Deliverable · 交付物（计入实验参与 20%） ① environment.yml；② 完成练习的 notebook（含思考题）；③ GitHub 仓库链接。
截止：下周一 23:59。晚交每日扣 10%。Submit env file + notebook + GitHub link by next Monday 23:59; -10%/day late.
