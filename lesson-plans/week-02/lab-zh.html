实验 1 · 只用张量与 autograd 实现线性回归

⏱ 每周 180 分钟一体课 · 本教案覆盖实验部分 80 分钟 + 小测与小结 10 分钟 📚 教材 2.4–2.6 🔧 随堂实验 🧩 教案编号：LP-W2-B 🌐 中文

1. 教学目标

知识目标

  • 说出一次参数更新的四个动作，并解释顺序为什么不能颠倒
  • 解释 .grad 为什么必须清零，以及不清零时损失曲线长什么样子
  • 解释基线损失在训练之前证明了什么
  • 区分数据生成真值、闭式最小二乘解与训练解三个数
  • 解释为什么即使不报错也必须检查形状

能力目标

  • 用固定种子生成合成数据，并算出 w = b = 0 时的基线 MSE
  • 只用张量与 autograd 训练线性回归——不许出现 nn.Module、不许出现 torch.optim
  • 在同一张图上画出三种学习率的损失曲线，并各自给出一句正确解读
  • 算出闭式最小二乘解，并给出相对误差
  • 用报错原文记录形状踩坑，并写成一条 AI 协同记录
  • 推送 M2 里程碑：题目确定、DATA.md v0、数据可加载
素养目标（课程思政） 把错误留在记录里——形状报错与调试过程是能力证据，不是需要藏起来的扣分项。只贴成功结果的报告， 反而无法说明你是否真的动过手。严谨求实的底线：不编造输出、不美化曲线；换设备出现微小差异如实写明即可， 不要悄悄只留最好那一次。

2. 重点与难点

类别内容处理策略
重点手写训练循环；梯度清零；学习率三档；四列收敛对比表；形状踩坑记录教师现场写一遍循环（5 分钟），随后学生凭记忆重写而不是照抄；每段结束前必须打印一个形状或一个数值才能进入下一段
难点不报错的 (n,) 与 (n,1) 陷阱；正确读出三条曲线；「误差」到底跟谁比；解释 AI 生成的 bug 而不是默默修掉形状：第一次算损失之前先打印 y.shape 与 X @ w + b 的 shape；曲线：先预测再运行；对比：先争论表头里的「相对误差」分母是谁，唯一错的答案是不写；AI 记录：必须附上那句错误写法原文和它错在哪里

4. 关键活动设计

活动 1 · 算损失之前先印形状（实验 A，p23）

训练开始前，每人必须先打印 X.shape、y.shape、w.shape、b.shape，并断言 X @ w + b 的形状是 (100, 1)。把 y 写成 torch.randn(100) 的同学，会在这里而不是半小时后发现——而且这个错误本来永远不会报错。

活动 2 · 禁用库自查（实验 B，p24）

进行到一半时，每人对自己写的文件执行 grep -nE "nn\.|optim\." lab1_linear_regression.py，有任何命中就是违规。目的不是抠字眼：只有亲手写那一行更新，才能体会到优化器替你做了什么、以及它做了哪些你没让它做的事。

活动 3 · 先预测再画曲线（实验 C，p19）

每人先写下对 lr = 0.001 / 0.1 / 1.0 三档的预期：会收敛、会停滞，还是会发散。再与真实曲线对比。这样一来，机械的练习变成了校准练习，「学习率过大」这件事也在被讲出来之前就先变成了自己的经验。

活动 4 · 你刚算的是哪个误差？（实验 D，p20）

填表之前，先让全班争论分母：相对误差是相对真值、相对 OLS，还是相对上一步？三种都说得通，唯一错的答案是「不写」。这就是「一个数」和「一个结果」的分界线。

活动 5 · 复现别人的曲线（实验 E，p25）

两人互换仓库，只照对方的 README 复现他的损失曲线。缺种子、版本没固定、路径写死——问题会立刻暴露。随后每人写下自己 README 缺了什么。
