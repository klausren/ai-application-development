1. Learning Objectives

Knowledge

  • State the six data quality dimensions and the GIGO principle
  • Explain why NumPy vectorization is 10-100x faster than loops
  • Describe the four core Pandas operations (load/filter/aggregate/merge)
  • Recall the four key chart types and their use cases, and describe the 5-step EDA workflow and the 6-step cleaning workflow

Skills

  • Perform vectorized operations, slicing, and broadcasting with NumPy
  • Perform boolean filtering, groupby aggregation, and merge with Pandas — and avoid the chained-indexing trap
  • Create histograms, scatter plots, box plots, and heatmaps with Matplotlib/Seaborn
  • Apply missing-value decision paths and outlier detection methods (IQR / Z-score / domain rules)
Attitudes Build the engineering mindset that "data quality determines the model ceiling"; understand why 80% of AI project time goes to data processing; develop the professional habit of "looking at data before touching models".

4. Key Activity Design

Activity 1 · Six Data Quality Dimensions Quick Poll (L1, p7)

Project 4 real data problem scenarios (40% of phone numbers missing, ages inconsistent across systems, a 2015 housing-price dataset used to predict 2026, traffic flow collected only during daytime). Students vote on which quality dimension each scenario violates, then reveal one by one. This builds "dimension sense" first; the AI hiring-bias case then shows "defects get amplified systematically".

Activity 2 · Vectorization vs Loop Speed Showdown (L2, p10)

Live code in Jupyter: ① use a for loop to compute column means of a 1000×1000 matrix; ② use np.mean(axis=0). Time with %%timeit — students witness the 100x gap. At that moment, "vectorization" turns from concept to conviction.

Activity 3 · Titanic Survival Rate Exploration (L2–L3, p12 + p17)

One line — df.groupby(["Sex", "Pclass"])["Survived"].mean() — reveals "female + first-class survival rate 96.8%", more impactful than any text. Later, the EDA walkthrough page (p17) repeats the full reconnaissance process with the five steps; students follow along locally.

Activity 4 · Chart Selection Triage (L3, p15)

Give 4 data analysis questions (① What does the age distribution look like? ② Is there a relationship between fare and age? ③ Which class has the highest survival rate? ④ Which features correlate most?), students name the chart type within 30 seconds each. Correct answers: histogram/scatter/bar/heatmap. Reinforces the "question first, chart second" mantra.

Activity 5 · Missing-Value Decision Drill (L4, p20)

Present three scenarios (missing <5% / 5–30% / >30%); students walk the decision path aloud, stating the handling plan and the rationale. The instructor probes "why is it missing?" — distinguishing random vs systematic missingness. This is a direct rehearsal for Lab D cleaning practice.
