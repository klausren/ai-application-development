Neural Networks and Modelling with nn.Module

1. Learning Objectives

Knowledge

  • Explain what a single neuron can and cannot represent, and why a hidden layer changes that
  • Trace a forward pass with shapes: (N, 2) → (N, 8) → (N, 8) → (N, 2)
  • Compare sigmoid, tanh, ReLU and LeakyReLU by range, gradient behaviour and intended use
  • State why removing the hidden activation reduces a two-layer network to a linear model
  • State the four rules of building a model with nn.Module and what goes wrong when each is broken
  • Explain why all-zero initialisation leaves hidden units symmetric
  • Read an ablation table — config / parameters / accuracy / conclusion — and say which variable mattered

Skills

  • Compute the parameter count of a layer by hand (in × out + out) and verify it with sum(p.numel() ...)
  • Write an nn.Module subclass with layers in __init__, a shape-annotated forward, and logits as output
  • Diagnose a model that never trains by reading print(model)
  • Design a controlled experiment in which exactly one variable changes
  • Judge an AI-suggested architecture by testing it, not by accepting it
Attitudes Judge an architecture by fitness for the problem, not by size: a structure that is 1,500× larger and three points worse is a worse structure. Hold the same standard for advice — including advice from an AI — that arrives without evidence.

4. Key Activity Design

Activity 1 · One Line or a Curve? (L1, p5)

Draw make_circles — two concentric rings — on the board and ask the class to separate them with a single straight line. Nobody can: the best a line achieves is ≈0.47, and it does not matter where you put it. Add a hidden layer of eight units and sketch how each unit contributes one cut, and the piecewise-linear boundary assembles itself into a closed region. Then show the make_moons scatter and ask the same question — most will claim a line cannot work there either, and the measurement says otherwise (≈0.89). That surprise is the lesson: linear separability is a property you measure, not one you eyeball.

Activity 2 · Guess the Number Before Running (L2, p11–p12)

Before running the with/without-ReLU comparison on make_circles, ask the class to write down two numbers: the expected accuracy with ReLU and the expected loss of the no-activation run. Most will guess near 0.5 for the second — exactly right — but they will be surprised by how flat the curve stays for the whole run. Then run the identical comparison on make_moons and watch the two curves stay much closer (0.890 vs 0.953 — about 6 points, against 51 on circles). Ask which dataset they would have chosen, and what conclusion they would have drawn from it alone. The prediction-then-run format converts a chart into a result — and the follow-up converts a result into an experiment-design lesson.

Activity 3 · Break It on Purpose: Three Models That Never Train (L3, p15)

Show three short snippets: a layer held as a module-level global, a layer constructed inside forward, and a manual softmax on top of CrossEntropyLoss. Ask what each one prints and which one raises an error. The first two raise nothing, and the third raises nothing either — that absence of error is the lesson. The test is always print(model) plus a parameter count.

Activity 4 · Two Rows, 42 Parameters (L4, p19)

Read the ablation table aloud on make_circles, stopping on the two rows that both show 42 parameters — 0.473 and 0.980. Ask what single change separates them (one nn.ReLU()), then show the proof: after fitting, the no-activation network's outputs match x @ (W2W1).T + (W2b1 + b2) to within 1e-7, so it is one affine map. Then flip to the make_moons rows, where the same two configurations read 0.890 and 0.953, and let the class discover that the dataset, not the architecture, decided how visible the effect was. Finally note the 67,074-parameter row: over 200× the parameters of 2-64-2 for no gain at all — the synthesis ("capacity helps until it does not; what helps is the non-linearity") is theirs rather than yours.

Activity 5 · Audit the AI's Advice (L4, p21)

Paste an AI-generated architecture recommendation for this dataset onto the board ("use 3 layers of 256, add dropout, train 1,000 epochs"). Ask the class to name what the advice does not know: the sample count (1,000), the memory budget, and the fact that on 2-d data a 256-wide layer is 130× wider than the input. Then assign one row of the ablation table to test it — and a line for AI_USE.md either way.
