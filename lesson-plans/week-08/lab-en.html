1. Learning Objectives

Knowledge

  • State the fixed items of the experiment protocol and explain why each one is fixed
  • Explain why the vocabulary must come from the training split only, and what leaks when it does not (the model sees a mean of 1592 words; the full corpus has 3142)
  • Explain why 95.58% of the test documents fall short of max_len = 96, and what out[:, -1, :] returns on a short document
  • Explain why the pooling choice alone is worth 26.2 points (0.5027 against 0.2407) with everything else held fixed
  • Explain why masking is correctness, not an optimisation (bare mean → masked mean is +11.0 points)
  • Explain why last_step's macro F1 of 0.0711 is below the 6-class chance level of 1/6 ≈ 0.1667 while its accuracy of 0.2407 only looks weak

Skills

  • Write tokenise, build_vocab and encode, and keep the per-sample length lens alive to the pooling line
  • Build the model with nn.Embedding(padding_idx=0) → nn.LSTM(batch_first=True) → nn.Linear(6), and count its parameters (166,278 at seed 42)
  • Compute the masked mean (h * mask).sum(1) / mask.sum(1) and, in a second arm, pack with pack_padded_sequence
  • Train, plot the training and validation curves, and fill the four-arm pooling table with mean ± standard deviation over five seeds
  • Print the confusion matrix, name the worst class pair with its count, and present at least 3 misclassified passages with their model confidence
  • Ask an AI to generate the pipeline, locate the padding/masking error, and record the before/after accuracy difference in a three-column log
Attitudes · Civic Education Report an experiment that did not work, and report the metric that changed the conclusion. This lab keeps two uncomfortable facts in the report: the best arm reaches only 0.5027, and the same model reports macro F1 0.0711 — below chance — while its accuracy of 0.2407 reads as "merely weak". The user-centred habit is to report both numbers and explain the gap, because an accuracy-only report would ship a model that has almost stopped recognising its smallest classes.

5. Code Skeleton

Fill in the four pipeline functions and the model. The shape chain is (B, 96) ids → (B, 96, 64) embeddings → (B, 96, 96) LSTM outputs → masked mean (B, 96) → (B, 6) logits. The two pooling arms below are the whole point of the lab.

import re, collections, torch, torch.nn as nn
from torch.nn.utils.rnn import pack_padded_sequence

TOKEN = re.compile(r"[a-z][a-z'-]*")

def tokenise(text):                        # lowercase + regex; keep don't whole
    return TOKEN.findall(text.lower())

def build_vocab(texts, min_freq=2, cap=6000):
    freq = collections.Counter()
    for t in texts:                        # texts = TRAIN split only
        freq.update(tokenise(t))
    words = [w for w, c in freq.most_common() if c >= min_freq][:cap]
    return {"<pad>": 0, "<unk>": 1,
            **{w: i + 2 for i, w in enumerate(words)}}

def encode(text, vocab, max_len=96):
    ids = [vocab.get(w, 1) for w in tokenise(text)][:max_len]
    ids += [0] * (max_len - len(ids))      # pad to a fixed length
    return torch.tensor(ids)

class TextLSTM(nn.Module):
    def __init__(self, vocab_size, hidden=96, n_classes=6):
        super().__init__()
        self.emb  = nn.Embedding(vocab_size, 64, padding_idx=0)  # pad stays frozen
        self.lstm = nn.LSTM(64, hidden, batch_first=True)
        self.fc   = nn.Linear(hidden, n_classes)

    def forward(self, x, lens):
        e = self.emb(x)                      # (B, 96, 64)
        out, _ = self.lstm(e)                # (B, 96, 96)
        mask = (x != 0).unsqueeze(-1)        # (B, 96, 1)  1 = real token
        h = (out * mask).sum(1) / mask.sum(1).clamp(min=1)   # masked mean
        return self.fc(h)                    # (B, 6)

# the packed arm: same model, different last three lines
def forward_packed(self, x, lens):
    e = self.emb(x)
    order = torch.argsort(lens, descending=True)
    inv   = torch.argsort(order)
    packed = pack_padded_sequence(e[order], lens[order].cpu(),
                                  batch_first=True, enforce_sorted=True)
    out, (h, _) = self.lstm(packed)
    return self.fc(h[-1][inv])               # h[-1] = each sample's last REAL token

The two arms differ only in how (B, 96, 96) becomes (B, 96): a masked mean over real positions, or the packed last hidden state. Dropping the mask (the bare-mean arm) is worth −11.0 points; reading out[:, -1, :] without packing is worth −26.2 points. Run all four and fill the table.

6. AI Collaboration Protocol

Ask, test, label — and write the number

  1. Ask: prompt the AI to write a complete PyTorch LSTM forward pass for a 6-class text task with variable-length input, and to explain how it handles padding. Demand runnable code, not prose. Do not read the reference implementation first — get the AI's first draft.
  2. Find the bug (this is the graded part): work down the checklist against the AI's code. ① Does it accept lens? If not, it can only use [-1]. ② Is the vocabulary built on all data? That is leakage. ③ Is padding_idx=0 set? If not, the pad embedding receives gradient. ④ Is the pooling a masked mean or a bare mean? A bare mean is this week's 4th place.
  3. Measure: run the corrected code and the AI's original, and record the accuracy difference. Reference magnitudes: bare mean → masked mean is +11.0 points (0.3929 → 0.5027); [-1] → packed is +18.4 points (0.2407 → 0.4248).
  4. Record: keep the log in the report — the prompt, the AI's code, your change, the measurement, the verdict. A suggestion can be valid in general and still be irrelevant here; the third column, a number, is what is assessed.
Typical AI claims to check "Just take the last hidden state with out[:, -1, :]" ignores that 95.58% of the documents are shorter than max_len, so that position is a pad vector — measured, it costs 26.2 points. "You can build the vocabulary from the whole dataset" is leakage; it inflates the reported test accuracy and will not survive a real deployment. "Masking is an optional optimisation" is wrong; the bare mean is 11.0 points behind the masked mean. Each claim is labelled from the student's own measurement, not from the AI text.
